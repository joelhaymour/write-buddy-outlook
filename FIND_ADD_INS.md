# How to Find "Get Add-ins" in Outlook

The location varies by Outlook version. Try these:

## Method 1: File Menu (Most Common)

1. Click **"File"** in the top-left (next to "Home")
2. Look for one of these options:
   - **"Get Add-ins"** (newer versions)
   - **"Manage Add-ins"** (older versions)
   - **"Add-ins"** (some versions)

## Method 2: File → Options

1. Click **"File"** (top-left)
2. Click **"Options"** (bottom of left sidebar)
3. Click **"Add-ins"** in the left menu
4. At the bottom, change dropdown from "COM Add-ins" to **"My Add-ins"**
5. Click **"Go"** button
6. Click **"+ Add a Custom Add-in"** → **"Add from File"**

## Method 3: Settings Menu

1. Click the **gear icon** (⚙️) in the top-right
2. Look for **"Get Add-ins"** or **"Manage Add-ins"**
3. Or go to **"View all Outlook settings"** → **"Mail"** → **"Add-ins"**

## Method 4: Ribbon (Rare)

Some versions have it in the ribbon:
- Look for an **"Add-ins"** tab in the ribbon
- Or check the **"Home"** tab for an add-in button

## Method 5: Direct Path (Windows)

If you're on Windows, you can also:
1. Press **Windows key + R**
2. Type: `outlook.exe /safe`
3. Or try: Go to **File** → **Options** → **Add-ins** → **Manage: COM Add-ins** → **Go**
