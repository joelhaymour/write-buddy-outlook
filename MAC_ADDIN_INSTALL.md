# Installing Add-ins on Outlook for Mac

Outlook for Mac handles add-ins differently than Windows. Here are the methods:

## Method 1: Via Outlook Menu (Mac-specific)

1. **Click "Outlook" in the top menu bar** (next to the Apple logo)
2. Look for **"Preferences"** or **"Add-ins"**
3. Or try: **"Tools"** → **"Add-ins"**

## Method 2: Check if Add-ins Tab Exists

1. **Compose a new email** (click "New Mail")
2. Look at the **ribbon/toolbar** at the top
3. See if there's an **"Add-ins"** tab or button
4. If yes, click it and look for "My Add-ins" or "Manage Add-ins"

## Method 3: Use Outlook Web (Alternative)

If the desktop app doesn't support custom add-ins on Mac, you might need to:

1. **Go to Outlook on the web**: https://outlook.office.com or https://outlook.live.com
2. **Click the gear icon** (⚙️) in top-right
3. **Click "View all Outlook settings"**
4. **Go to "Mail"** → **"Add-ins"**
5. **Click "My Add-ins"** tab
6. **Click "+ Add a Custom Add-in"** → **"Add from File"**

## Method 4: Check Outlook Version

Some older versions of Outlook for Mac don't support custom add-ins. Check your version:

1. **Click "Outlook"** in menu bar
2. **Click "About Outlook"**
3. Note the version number

**Minimum requirements:**
- Outlook for Mac 2016 or later
- Office 365/Microsoft 365 subscription (for newer features)

## Method 5: Use Windows Outlook (If Available)

If you have access to a Windows computer:
1. Install the add-in there
2. It should sync to your Mac Outlook (if using same account)
