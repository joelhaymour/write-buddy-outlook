# Outlook Web vs Desktop - Add-in Installation

## Important: Custom Add-ins Require Desktop App

**Outlook on the web (outlook.com)** does NOT support custom add-ins from files. You need the **Outlook desktop app** (Windows or Mac).

## How to Tell Which You're Using

### Outlook Desktop App:
- Standalone application (not in browser)
- Usually has "File" menu in top-left
- Can install custom add-ins from files

### Outlook on the Web:
- Opens in a web browser
- URL starts with `outlook.live.com` or `outlook.office.com`
- Settings look like what you're seeing
- **Cannot install custom add-ins from files**

## Solution: Use Outlook Desktop App

If you're using Outlook on the web, you need to:

1. **Download Outlook Desktop App** (if not installed):
   - Go to https://www.microsoft.com/microsoft-365/outlook/email-and-calendar-software-microsoft-outlook
   - Sign in and download Outlook for Mac or Windows

2. **Open Outlook Desktop App** (not the web version)

3. **Then follow these steps:**
   - Click **File** (top-left)
   - Look for **"Get Add-ins"** or **"Manage Add-ins"**
   - Or: **File** → **Options** → **Add-ins** → Change dropdown to **"My Add-ins"** → **"Go"**

## Alternative: Check Mail Section

If you ARE using the desktop app, try:

1. In Settings, click **"Mail"** (in the left navigation)
2. Look for **"Add-ins"** in the Mail sub-categories
3. Click it to see add-in options
